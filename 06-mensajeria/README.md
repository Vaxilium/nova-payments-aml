# 06 — Mensajería financiera

Propósito: modelar, validar y simular los mensajes de pago locales e internacionales.

Contenidos esperados:
- Catálogo ISO 20022: `pacs.008`, `pacs.002`, `pain.001`, `camt.053`.
- Mapeo MT103 ↔ ISO 20022.
- Validador de IBAN, BIC, ISO 4217, importes y campos obligatorios.
- Simulador de pago instantáneo tipo SPI con máquina de estados.
- Casos de rechazo, reintento y conciliación.
- Tests de validación y mapeo.

Estado: **pendiente — Fase 4**.
Regla: toda referencia a estándares debe citar fuente oficial en `docs/FUENTES.md`.
