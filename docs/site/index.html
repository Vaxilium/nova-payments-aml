01 / El caso

Un solo caso, todas las capas del problema.

El objetivo no es juntar documentos. Es demostrar que un BA puede conectar una necesidad de negocio con procesos, requerimientos verificables, un sistema funcional y evidencia de calidad.

Negocio

Entender la tensión

Velocidad para el cliente, control para el banco y trazabilidad para auditoría. BRD, stakeholders, riesgos, KPIs y contexto regulatorio.

Diseño

Convertirlo en contrato

6 BPMN, 4 DMN, 10 épicas, 40 historias Gherkin, 198 story points y 16 NFR con criterios de aceptación.

Sistema

Demostrarlo funcionando

Core SQLite con partida doble, API FastAPI idempotente, ISO 20022/MT103, 12 reglas AML y un dashboard reproducible.

02 / Demo reproducible

Una transferencia, un mensaje y una retención AML.

La demo corre sobre una copia temporal de SQLite. Ejecuta una transferencia local, muestra la partida doble y una retención AML por alto valor. No modifica la base del repositorio ni usa PII.

$ python -m scripts.demo
  • Core: transferencia PYG con asiento equilibrado.
  • Mensajería: `pacs.002` PDNG / AMLHOLD.
  • Compliance: decisión HOLD por alto valor.
  • Salida: GIF y HTML generados por código.

05 / Límites

Lo que el prototipo no hace también es parte del entregable.

  • No hay conectividad real con SPI, SWIFT, corresponsales ni cámaras.
  • No hay autenticación, autorización ni certificación XSD.
  • No se declara rendimiento, alta disponibilidad ni RTO/RPO.
  • No se operaron Jira, Figma, Power BI, Tableau ni Camunda; sus artefactos están listos para importar.
