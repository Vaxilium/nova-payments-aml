# docs — Gobernanza del proyecto

Documentación transversal que aplica a todas las fases.

| Documento | Propósito |
|---|---|
| [SUPUESTOS.md](SUPUESTOS.md) | Decisiones y supuestos registrados con fecha e impacto |
| [PENDIENTES.md](PENDIENTES.md) | Bloqueos, deuda y acciones que requieren al autor |
| [FUENTES.md](FUENTES.md) | Fuentes oficiales verificadas y su uso |
| [EVIDENCIAS.md](EVIDENCIAS.md) | Pasos manuales, capturas y enlaces de herramientas |

Reglas:
- Toda decisión tomada sin consulta se registra en `SUPUESTOS.md`.
- Todo lo no verificable se marca `SUPUESTO NO VERIFICADO` en su documento y se lista en `PENDIENTES.md`.
- Ninguna herramienta se declara usada sin evidencia real.
