# 07 — AML y compliance

Propósito: demostrar el ciclo AML integrado: conocer al cliente, monitorear, investigar y reportar.

Contenidos esperados:
- Modelo KYC/CDD y estados del cliente.
- Reglas de monitoreo transaccional en SQL (umbrales, velocidad, geografía, estructuración).
- Screening de listas ficticias de sanciones/PEP.
- Motor de alertas y priorización por riesgo.
- Flujo de investigación y ROS ficticio.
- Mapeo normativo (SEPRELAD, GAFI) con fuentes oficiales.
- Tests de reglas positivas y negativas.

Estado: **pendiente — Fase 5**.
